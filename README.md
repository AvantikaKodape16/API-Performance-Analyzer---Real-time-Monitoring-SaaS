A production-ready SaaS platform for monitoring, analyzing, and tracking API performance metrics in real-time. Features real-time dashboards, intelligent alerting, performance trends, and background job processing with Celery + Redis. Full-stack application built with Django REST Framework, React, PostgreSQL, and containerized with Docker.

----

Key Features

📊 Real-time performance metrics & analytics
⚡ Add unlimited API endpoints to monitor
🚨 Intelligent alert system for slow APIs & errors
📈 Interactive charts & performance trends
🔄 Celery + Redis for reliable background monitoring
🐳 Docker-ready for instant deployment

----

Tech Stack

Backend: Django, DRF, PostgreSQL, Celery, Redis
Frontend: React, Recharts, Axios
DevOps: Docker, Docker Compose
